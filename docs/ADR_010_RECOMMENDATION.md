# ADR-010 — harness recommendation

**Status:** NOT READY — comparative evidence is insufficient, and the only verified 64K-capable GPU endpoint is not reachable from the isolated candidate network.

No harness is recommended at this checkpoint. A and C passed the repeated family 1 inventory screen. For family 2, both completed one compound trajectory 3/3 on Qwen3-8B. On a second trajectory, the 8B model omitted Pasta in 3/3 attempts for each candidate and returned a completion-style update; canonical reads exposed the partial effects. Both candidates completed that trajectory 3/3 on Qwen3-14B with verified state. This is evidence that model capability contributes to the failure, not enough to establish general 8B/14B reliability or choose a harness. A bounded homelab discovery found a functioning Qwen3.6 35B GPU endpoint with an observed serving context of 65,536 and generation on four GPUs; it meets Hermes's numeric context floor. The experiment's candidate network remains isolated from that endpoint, so A/B/C have not been compared on it. One matched attempt per candidate on a new private 8B wording exceeded five minutes without a tool action; C returned HTTP 502, and A was operator-cancelled after six minutes. This incomplete screen is not a comparative result. See [MODEL_PROFILE.md](MODEL_PROFILE.md) and [COMPARISON_REPORT.md](COMPARISON_REPORT.md).

A recommendation still requires the full eight-family screen, private held-out cases, repeated controlled trials, independent outcome verification, safety-gate results, restart and maintenance exercises, the eligible common-model comparison, living v2 observations, and owner-facing evaluation specified by the experiment plan and historical review. The exact family 1 and 2 evidence and limitations are in [COMPARISON_REPORT.md](COMPARISON_REPORT.md).

Do not interpret NOT READY as evidence that a particular candidate failed or that v3 should replace HADES v2.
