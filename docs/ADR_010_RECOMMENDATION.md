# ADR-010 — harness recommendation

**Status:** NOT READY — experiment not yet run.

No harness is recommended at this checkpoint. Repository setup and a source-only v2 revision observation do not provide candidate comparison evidence. A recommendation requires the shared disposable contracts, controlled trials, independent outcome verification, safety-gate results, maintenance exercises, and owner-facing evaluation required by the experiment plan and historical review.

Do not interpret NOT READY as evidence that a particular candidate failed or that v3 should replace HADES v2.
